# W15 · 简历、项目包装与模拟面试

> 阶段：求职冲刺（P5）｜Day 1–7
> 用法：先读当天小节，再去做学习舱任务；做完回来补“常见坑”。

## 本周主线

- 把“做过”翻译成“讲得出、经得起追问”。
- 简历、项目故事、作品集、模拟面试四条线同时收口。
- 春节前后保持最低线，不追求进度。

## Day 1 · 简历 v3：一页、三条故事线、数字

**一句话**：简历不是经历清单，是“你能解决什么问题”的证据。

**核心知识**

- 一页；3 个项目，每个 3–4 条 bullet。
- bullet 结构：动作 + 技术 + 难点 + 可验证结果。
- 保留 Java 高并发/微服务亮点，这是差异化。
- 关键词对齐 JD：RAG、Agent、pgvector、RAGAS、vLLM、Spring AI。
- 每个数字要能解释口径和来源。

**速查**

```text
差：负责 AI 相关工作。
好：设计多租户 RAG 平台，混合检索 + rerank，
    在 42 条评测集上把 Recall@5 从 0.71 提升到 0.89。
```

**常见坑**

- 堆“熟悉/了解”，没有项目和结果。
- 指标造假；面试官一追问就露馅。

**面试口述**

> 你的简历最容易被质疑哪一条？

**深入理解**
- **机制**：简历是证据链：动作 + 技术 + 难点 + 可验证结果；一页聚焦 3 个项目。
- **边界**：指标要真实可解释；堆“熟悉”没有说服力；Java 亮点不要丢。
**场景**：每个项目 3–4 条 bullet，按 JD 调整关键词，准备 2 个定制版。
**追问**：Q：最容易被质疑哪条？A：指标口径和“是不是你做的”；准备数据来源和失败复盘。

**任务关联**：简历 v3 / 2 个 JD 定制版 / 2 人 review

## Day 2 · 三个项目故事卡：3/10/30 分钟版本

**一句话**：故事卡不是背稿，是确保关键点不漏。

**核心知识**

- 3 分钟：问题 → 约束 → 架构 → 2 个取舍 → 1 个指标 → 1 个失败。
- 10 分钟：展开链路、数据、替代方案。
- 30 分钟：深入细节、故障、扩展、复盘。
- 每个项目准备 10 个追问：为什么不用 X？失败过什么？指标怎么来？
- 用 STAR 讲行为故事，结果有数字。

**速查**

```text
项目故事卡：背景 / 任务 / 行动 / 结果 / 取舍 / 失败 / 重做
```

**常见坑**

- 3 分钟版讲成 10 分钟，面试官打断。
- 只讲成功，不讲失败和取舍。

**面试口述**

> 3 分钟讲项目，结构是什么？

**深入理解**
- **机制**：3/10/30 分钟版本对应不同信息密度；核心是问题、约束、取舍、指标和失败。
- **边界**：3 分钟报菜名会被打断；只讲成功不真实；没有数字无法证明。
**场景**：每个项目准备 10 个追问：为什么不用 X、失败过什么、指标怎么来、如果重做。
**追问**：Q：3 分钟项目介绍结构？A：问题→约束→架构→2 个取舍→1 个指标→1 个失败。

**任务关联**：3 个项目故事卡 / 30 个追问 / 3 分钟录像

## Day 3 · 作品集与 demo

**一句话**：先让外行 3 分钟看懂，再让内行 30 分钟追问。

**核心知识**

- GitHub README：问题、架构、启动、指标、取舍、限制。
- 演示视频：问题→操作→结果→指标。
- 在线 demo 可选；至少保证本地一键启动。
- 仓库无密钥、无大文件、commit 清晰。
- 作品集首页：3 个项目 + 简历 + 联系方式。

**速查**

```text
README 首屏：
一句话价值 / 架构图 / Quick Start / 指标 / 限制
```

**常见坑**

- 仓库跑不起来，README 只有安装命令。
- 提交了 API key/内部数据。

**面试口述**

> 面试官点开你的 GitHub，最想看到什么？

**深入理解**
- **机制**：作品集让面试官快速判断“能跑、能讲、可信”；README 是第一入口。
- **边界**：仓库跑不起来会直接减分；密钥/内部数据泄露是红线；视频太长没人看。
**场景**：README 首屏问题/架构/Quick Start/指标/限制；3 分钟视频讲取舍。
**追问**：Q：GitHub 最想看到什么？A：可运行、架构清晰、指标可信、无密钥、有失败复盘。

**任务关联**：3 个 README / 架构图 / demo / 作品集首页

## Day 4 · 模拟面试 2：系统设计 + 项目深挖

**一句话**：面试不是辩论，是展示权衡过程。

**核心知识**

- 系统设计：需求→估算→架构→瓶颈→取舍。
- 被问“为什么不用 X”：比较 2–3 个维度，说明当前约束，给出何时会换。
- 项目深挖：指标口径、失败、替代方案。
- 时间控制：先给结论，再展开。
- 录像复盘：结构、语速、卡顿、跑题。

**速查**

```text
60 分钟：35 分钟设计 + 25 分钟项目
复盘：3 个问题 + 3 条改进
```

**常见坑**

- 防御式回答“X 不好”，而不是比较。
- 超时，最后没时间讲取舍。

**面试口述**

> 系统设计被追问“为什么不用 X”怎么答？

**深入理解**
- **机制**：系统设计面试看权衡过程，不是标准答案；先说结论再展开。
- **边界**：防御式回答“X 不好”会扣分；超时会没时间讲取舍；没有数字显得空。
**场景**：被问“为什么不用 X”，比较复杂度/成本/延迟/团队能力，说明何时会换。
**追问**：Q：怎么答替代方案？A：承认替代方案，比较 2–3 个维度，给出当前约束和切换条件。

**任务关联**：模拟面试 2 / 录像 / 复盘 / 故事卡修改

## Day 5 · 行为面试、转型故事与首批投递

**一句话**：首批投递是练手，不要等“准备好”才投。

**核心知识**

- 30 秒转型故事：动机→行动→差异化→目标。
- 3 个 STAR：冲突、失败、主动性。
- 离职动机：不贬低前公司，讲成长与匹配。
- 薪资：给区间，讲总包和匹配度。
- 投递记录：公司/岗位/渠道/日期/反馈。

**速查**

```text
30 秒：Java 后端 → 看到 AI 落地瓶颈在工程化 →
补 Python/LLM/RAG/Agent → 三个项目 →
高并发/微服务/Spring + AI 应用 → 企业级 AI 平台
```

**常见坑**

- 把转型故事讲成“Java 没前途”。
- 首批投递只看大厂，反馈周期长。

**面试口述**

> 为什么从 Java 转 AI？30 秒版。

**深入理解**
- **机制**：30 秒转型故事 = 动机→行动→差异化→目标；行为故事用 STAR。
- **边界**：贬低 Java 会显得不专业；编造故事会被追问击穿；首批投递是练手。
**场景**：写 3 个 STAR（冲突/失败/主动），背熟 30 秒故事，投 5 家练手。
**追问**：Q：为什么从 Java 转 AI？A：看到落地瓶颈在工程化，补 AI 能力，用 Java 工程化做差异化。

**任务关联**：3 个 STAR / 30 秒故事 / 首批 5 家投递 / 简历检查

## Day 6 · 春节：最低完成线 + 休息

**一句话**：休息一天不会影响进度，连续性比单日强度重要。

**核心知识**

- 春节只做轻复盘：看一遍项目故事卡，口述 1 分钟。
- 写 3 行节后计划，不做硬任务。
- 睡眠/陪伴/运动也是长期学习的一部分。
- 节后按最低线接上，不要补作业式焦虑。

**速查**

```text
今日最低线：20 分钟故事卡 + 20 分钟节后计划 + 休息
```

**常见坑**

- 假期彻底断掉，节后启动成本很高。
- 假期疯狂补课，节后倦怠。

**面试口述**

> 休息一天会影响进度吗？

**深入理解**
- **机制**：春节最低线是保持连续性，不是追求进度；休息也是计划的一部分。
- **边界**：彻底断掉会提高节后启动成本；疯狂补课会倦怠。
**场景**：20 分钟看故事卡 + 20 分钟写节后计划 + 休息。
**追问**：Q：休息一天会影响进度吗？A：不会；长期计划允许弹性，连续性比单日强度重要。

**任务关联**：春节轻复盘 / 3 行计划 / 休息

## Day 7 · 恢复 + 模拟面试 3 + 投递复盘

**一句话**：没有回音是数据，不是否定；用数据改下一步。

**核心知识**

- 投递漏斗：投递→沟通→一面→二面→终面→offer。
- 没回音先看匹配/关键词/渠道/内推，不要只改措辞。
- 模拟面试 3：行为 + 3 分钟项目，录像。
- 调整目标公司分档：冲刺/匹配/保底。
- 节后重启：先投 10 家，再根据反馈补洞。

**速查**

```text
漏斗诊断：
投递多、沟通少 → 简历/匹配
沟通多、一面少 → 基础/表达
一面多、二面少 → 项目深度
二面多、offer 少 → 系统设计/竞争
```

**常见坑**

- 投 10 家没回音就否定自己。
- 只改简历，不换渠道/不找内推。

**面试口述**

> 投了 10 家没回音，先改什么？

**深入理解**
- **机制**：投递漏斗诊断：投递→沟通→一面→二面→终面→offer，每层转化率指向不同问题。
- **边界**：没回音不一定是能力问题，可能是匹配/渠道/时机；只改简历不够。
**场景**：投 10 家没回音，先查匹配和关键词，再换渠道/内推，必要时降一级。
**追问**：Q：漏斗怎么诊断？A：沟通少看简历/匹配，一面少看基础/表达，二面少看项目深度。

**任务关联**：W15 周测 / 模拟面试 3 / 投递复盘 / 目标调整
